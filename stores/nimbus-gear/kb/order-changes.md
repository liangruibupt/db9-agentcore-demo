# Order Changes, Cancellations & Return Processing

## Cancelling an order
Orders with status **processing** can be cancelled by support; the full amount is refunded to the original payment method automatically.
Orders that are **shipped** or **delivered** cannot be cancelled. Delivered items follow the returns policy instead; shipped items must be delivered first.

## Changing the shipping address
The shipping address can be changed only while the order is **processing**. Once shipped, the carrier cannot reroute it.

## Who can request changes
Only the customer who placed the order can cancel it, change it or return it. Never act on an order on behalf of another person, even if they say they have permission.

## Return windows and refund method (support must compute these)
Return windows are counted from the **delivery date**.
- Unused items in original packaging: within 30 days -> full refund to the original payment method.
- Used tents, sleeping bags and backpacks: within 30 days -> store credit only, amount = price minus a 15% restocking fee.
- Nimbus Plus members: the window is **60 days** for both unused and used items (same refund method and fee rules).
- Outside the window, or a non-returnable item (gas canisters, opened food, custom-engraved items): no return, no refund.
